# OSBB_cl

Чистый каркас проекта OSBB, начатый заново — отдельный git,
отдельный config.py, только то, что реально служит цели: довести
Telegram-кассира до пилотной эксплуатации.

Подсистемы:
- `core_new/` — слой доступа к данным (adapters/, domain/)
- `finance_core/` — финансовые правила (в т.ч. неразнесённые платежи)
- `presentation/` — пользовательский интерфейс (Telegram-бот)
- `dev_infrastructure/` — инструменты разработки (триаж, дедупликатор и т.п.)
- `data/` — база данных, сырые данные, логи, экспорты
- `migrations/` — история миграций схемы БД
- `docs/` — курированная документация
